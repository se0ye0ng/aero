# 드론 부위 식별 연습: 먼저 읽어 주세요

**추가 배포·검토 중단:** 자유롭게 부위를 선택하는 이 양식은 검토자 간 좌표
일치도를 측정할 수 없습니다. A의 응답은 탐색 자료로 보존하며 추가 사람 검토를
정합 개선의 선행 조건으로 요구하지 않습니다. 현재 작업은
[자동 정합 개선 실험](registration_automatic_repair.md)입니다.
아래 설명은 이전 연습의 기록이며 추가 검토 요청이 아닙니다.

이 자료는 정답(GT) 수집이나 검토자 합격 시험이 아닙니다. 일반 검토자가
부품 설명을 이해하고 실제 RGB/IR 영상에서 같은 부위를 식별할 수 있는지
확인하는 **6쌍의 예비 연습**입니다. 이전48쌍 작업은 보류합니다.

## 사용 방법

1. 각자 받은 압축을 풉니다. A는 `practice_A.html`, B는 `practice_B.html`을
   브라우저에서 엽니다. `images` 폴더를 HTML과 같은 위치에 유지합니다.
2. 부품 그림과 주의사항을 먼저 읽고 설명 확인 질문에 답합니다.
3. 검토자 이름/별칭을 입력합니다. 두 사람은 서로 답을 먼저 보지 않습니다.
4. 각 영상에서 동체, 팔, 프로펠러, 회전축 중심이 구별되는지 선택합니다.
5. 두 영상의 **동일한 실제 부위**임을 구별할 수 있는지 선택합니다.
   자신 있게 구별될 때만 항목을 고르고 두 영상에서 그 부위를 클릭합니다.
   주황색 원은 자신의 연습 표시이며 모델 정답이 아닙니다.
6. 불분명하면 점을 억지로 찍지 말고 어려운 이유를 적습니다.
7. 해당 영상의 답변 완료를 체크합니다. 6쌍을 본 뒤 JSON을 저장합니다.
   중간 저장도 가능합니다. 자동 저장이나 서버 전송은 없습니다.
8. `practice_A.json`, `practice_B.json`을 각각 전달합니다. 결과는 사람이 다시
   검토합니다. 둘이 같은 답을 해도 자동으로 GT나 qualification PASS가 되지 않습니다.

## 무엇을 찾나요?

- **모터:** 프로펠러를 돌리는 부품. 내부 회전자/고정자를 식별하는 시험이 아닙니다.
- **프로펠러:** 회전하는 날개. 날개 끝은 모터 중심과 다릅니다.
- **모터/회전축 중심:** 실제로 축 위치를 구분할 때만 고릅니다. 팔 끝이나 가장 밝은
  열점을 보고 보이지 않는 축 위치를 추정하지 마세요.
- **팔(암):** 동체에서 모터로 이어지는 구조.
- **동체:** 중앙 몸체. 단순한 덩어리의 중심 대신 실제로 식별되는 모서리만 점 후보입니다.
- **착륙 다리:** 착륙 때 지지하는 구조. 가려지면 선택하지 않습니다.

그림은 직접 그린 일반적인 구조 개념도입니다. 실제 기종, 모터 번호나 전후좌우를
지정하지 않습니다. [ArduPilot 공식 부품 안내](https://ardupilot.org/copter/docs/what-you-need.html)를
추가로 참고할 수 있으나, 이 링크를 보지 않아도 연습 설명을 읽을 수 있습니다.

## 피해야 할 오해

흰색 꺾인 선/십자선/글씨는 화면 표시이지 드론 부품이 아닙니다. IR의 밝은 점은
모터일 수도 있지만 열 번짐 등으로 다른 위치일 수 있어 밝기만으로 판단하지 않습니다.
두 영상의 화면 왼쪽 부위가 항상 같은 물리 부위는 아닙니다. 확대해도 없는 세부
구조가 새로 생기지 않습니다. 드론 전체가 보여도 같은 모터를 구분하지 못할 수 있습니다.

**모름/보이지 않음은 중요한 결과이며, 실패하거나 잘못 답한 것이 아닙니다.**
지금은 uncertainty radius나 자유 입력 landmark ID를 요구하지 않습니다.

## 연구 담당자용 범위와 다음 단계

선정은 기존 train48 패널의 인덱스1,10,19,28,37,46으로 고정했습니다.
서로 다른6개 시퀀스의 중간 시점이며 성공 장면만 선별하지 않았습니다.
정답 박스는 화면에서 드론 주변을 확대하는 용도로만 사용합니다.
원본 PNG를 복사하며 리샘플 이미지는 저장하지 않습니다. 예측 대응점은 표시하지 않습니다.
이 연습 응답을 정합 정확도 측정용 독립 대응점 GT로 자동 승격하지 않습니다.

두 사람의 응답이 오면 먼저 부품 이해와 동일 부위 해석의 일치 여부를 검토합니다.
확신 응답과 클릭이 있어도 세부 구조가 실제로 보이는지는 별도 확인합니다.
식별 가능성이 확인된 후에만 명확한 항목 정의, 반복 표시를 통한 재현성 측정,
독립 검증 패널 설계를 진행합니다. 지금은 불확실성 반경이나 허용 오차를 만들어 넣지 않습니다.
